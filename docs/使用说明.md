# Research Paper Assistant 使用说明

## 启动

双击 `启动助手.cmd`，保持打开的命令窗口不关闭。浏览器访问 <http://127.0.0.1:8501>。脚本使用本机便携版 Ollama、项目目录中的模型和 Python 环境；关闭命令窗口会停止网页服务。

如果已有其他 Ollama 服务占用 11434 端口，启动脚本会复用该服务；它必须能访问 `qwen2.5:3b`，否则请先停止该服务，再运行启动脚本。

## 使用

- 已收录的实测论文包括 `On Agentic Manipulation Policies`（arXiv:2611.09892）。在“论文问答”中可以用中文或英文提问，回答下方及右侧引用卡片附带置信度与相关度标签（如 `高相关 0.85`、`中相关 0.65`），便于快速甄别核心学术证据。
- “单篇精读”用于选择单篇论文，支持结构化速读（核心方法、实验对比、局限与未来方向一键提炼）与针对性提问。新生成的速读记录附带生成时使用的参考片段，可直接点击“查看原文”。这些片段并非逐句引用，结论仍需核对。
- 右侧“论文”可选择本地论文并按页预览；在“引用”中展开最近一次回答或速读的参考片段，点击“查看原文页面”可定位对应页。系统会尝试高亮匹配文本；PDF 排版或文本差异可能导致无法匹配。可一键清除高亮，并通过图片放大按钮查看细节。
- 窗口较窄时（约 1150 像素以下），右侧“资料与来源”会自动移到问答区下方并占满一行，避免被压缩到难以阅读；在侧栏关闭“显示资料与来源”可只保留问答区。
- 左侧可新建、切换、重命名与删除对话，每个对话独立保存问答记录、阅读范围、速读结果和来源位置。对话自动保存在项目的 `data/conversations.sqlite3`，重新打开应用时加载；通过每个对话旁的菜单可重命名或删除，也可在“管理全部对话”中清空记录。
- 侧栏“获取新论文”会访问 arXiv 并按 `research_assistant/config.py` 中的主题导入；默认最多抓取 3 个主题各 5 篇，处理可能较慢。导入完成后页面会提示成功/失败篇数或无新论文更新，详细异常可查看控制台日志。
- 支持中文和英文提问，模型会尽量使用提问的语言回答；摘要默认使用中文。自动生成的结论和引文需回到论文原文核对。

## 当前配置

- 生成模型：`qwen2.5:3b`，本地 Ollama。
- 嵌入模型：`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`，本地缓存。与上游默认模型不同，后续对比实验应固定模型和知识库。
- 检索：FAISS 向量检索 + BM25 关键词检索 + RRF 融合；当前未完成纯向量与混合检索的效果对比。
