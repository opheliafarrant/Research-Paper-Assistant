# 论文阅读助手架构

项目参考 Mini ReAct Agent 的分层、组合入口和清晰的模块边界，按当前功能保持轻量，不引入 Agent、MCP 或插件框架。

```text
启动助手.cmd → research_assistant/presentation/streamlit_app.py → bootstrap.py
                                                               ├─ application/  导入、论文列表、问答和摘要
                                                               ├─ domain/       数据契约、RRF 融合
                                                               └─ infrastructure/ arXiv、PDF、嵌入、索引、本地文件、Ollama
```

`bootstrap.py` 负责把外部适配器注入应用服务。`research_assistant/config.py` 是配置入口；论文、索引和导入记录分别位于 `data/pdfs/`、`data/cache/`、`data/ingested.txt`，数据格式保持不变。旧版根目录兼容脚本已移除，命令行操作统一使用 `python -m research_assistant`。

界面使用左侧会话列表、中间问答和右侧资料面板。会话及阅读状态通过独立 SQLite 存储保存在本地，浏览器会话负责当前交互；PDF 预览由 `infrastructure/pdf_preview.py` 按索引中的一基页码渲染，并在内存中绘制可匹配的引用高亮，不修改原文件。

## 验证

在项目目录执行：

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -p 'test_*.py'
$env:HF_HOME = "$PWD\.hf-cache"; $env:HF_HUB_OFFLINE = '1'; .\.venv\Scripts\python.exe -B -m tests.verify_isolated_ingestion
$env:HF_HOME = "$PWD\.hf-cache"; $env:HF_HUB_OFFLINE = '1'; .\.venv\Scripts\python.exe -B -m tests.verify_live_ui
```

第二项将现有样本 PDF 复制到临时目录，再实际解析并建立临时 FAISS 和 BM25 索引，不修改已有论文库。第三项使用已收录的样本论文、现有索引和本地 Ollama，实际测试中英文问答及中文摘要；这两项均需要本地模型就绪。单元测试不能代替实际模型和界面测试。
